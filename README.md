# LLM-Assisted Visual Data Analysis

This prototype supports exploratory visual data analysis using U.S. Census data as an example. It allows users to 1) create common visualizations, such as bar charts, heatmaps, scatterplots, and histograms, through drag-and-drop interactions and 2) analyze data subsets using brushing and linking techniques.

The system is implemented as a Node.js web application using the Express framework.

## Running the Application

To run the app locally:
1. Ensure that Node.js is installed on your system.
2. Install project dependencies by navigating to the project folder and running: npm install
3. Start the server in debug mode: DEBUG=prototype:* npm start
4. Open your browser and go to: http://localhost:5050/
